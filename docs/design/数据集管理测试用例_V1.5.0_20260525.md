### 1.4 阶段标记（与验收清单 §1.5 对齐）

用例表可增加列 **阶段**：`M` = Mock 可执行；`R` = 仅真实实现后可执行。未标者默认 **R**（契约型在 Mock 上可跑子集，但结论不替代 R）。

### 1.5 现状说明（Mock vs 真实）

- **Mock**：导入几乎即时成功、**可不校验 `Content-Range`**、`errorCode`/异步与生产可能不一致；pytest 4 条仅覆盖主流程。
- **真实**：以验收清单 V1.5.0 全表为准；**分片**须满足清单 **I-11a～I-11f**；**新视野供应商**须满足 **NV-01～NV-10**；**导出**须满足 **X-01～X-13**；OCT 多帧须满足 **I-44～I-45**。

### 1.6 已与评审对齐的固定约定（非性能类）

以下替代初版中「422 or 业务码」「二选一」等模糊表述：

| 话题 | 固定约定 | 未实现时 |
| --- | --- | --- |
| 缺必填、类型错误、越界 query | **HTTP 422** + `DATASET_VALIDATION_ERROR`（或 OpenAPI 中单表细码） | Mock 可暂不测，上真实前补 |
| 业务阻断（§7.1） | **HTTP 400** + 设计 `errorCode` | Mock 已部分覆盖 |
| 资源不存在 | **HTTP 404** | — |
| **秒传全新 hash**（无已合并、无未完成任务） | `hit=false`，`fileId=null`，`uploadId=null`，`uploadedParts=[]`；前端再调 **API-04** 新建任务 | 写入 OpenAPI，与本用例 TC-API-03-N03 一致 |
| **`pageNo` 非法**（如 0、负数） | **HTTP 422**，不默认回退第 1 页 | 与 TC-C-003 一致 |
| **`GET images` 缺 `surveyDate`** | **HTTP 422** | 与 TC-API-15-E01 一致 |
| **导出分页 offset** | `offset` 从 0 开始；`limit` 默认 20，建议最大 100，非法值按 422 处理 | 与 TC-API-18-E01 一致 |
| **导出下载计数** | `downloadCount` 由后端 `export_record.download_count` 返回；有效下载请求每次递增 1，未通过鉴权/已过期/不可下载不计数 | 与 TC-API-18-N04、TC-API-19-N04、TC-X-011 一致 |
| **导出过期错误** | 已过期下载建议 HTTP 410 + `DATASET_EXPORT_EXPIRED`；若平台暂不支持 410，也必须返回明确不可下载错误且不返回 zip | 与 TC-X-004、TC-S-003 一致 |

**与主站冲突时**：以网关/主应用统一规范为准，并回写 **验收清单 §1.6**。
